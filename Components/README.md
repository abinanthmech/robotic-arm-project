# Components

The following components were used to develop the 6-DOF Robotic Arm project.

## Hardware Components

- ESP32 Microcontroller
- Servo Motors
- Servo Motor Mounting Brackets
- Power Supply Unit
- Jumper Wires
- Voltage Converts
- Screws, Nuts and Bolts
- Other Mechanical and Electrical Components

The photographs of the components used in the project are included in this folder for reference.
