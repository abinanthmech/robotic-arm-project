# Calibration

## Home Positions

The programmed home positions of the six servos are:

| Servo | Home Position |
|---|---:|
| Base | 151° |
| Shoulder | 45° |
| Elbow | 128° |
| Wrist Pitch | 1° |
| Wrist Roll | 58° |
| Gripper | 102° |

## Purpose

The home position provides an initial reference position for the robotic arm when the system starts or when the HOME command is used.
