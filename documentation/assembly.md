# Assembly

## Overview

The robotic arm was assembled using a ready-made robotic arm kit purchased from Robo.com

The project was assembled and upgraded using an ESP32-based control system.

## Main Components

- Robotic arm mechanical structure
- ESP32
- 6 servo motors
- Servo connections
- Power supply
- Control software

## Servo Positions

The robotic arm has six servo-controlled joints:

1. Base
2. Shoulder
3. Elbow
4. Wrist Pitch
5. Wrist Roll
6. Gripper
