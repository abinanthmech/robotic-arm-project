# Troubleshooting

## Servo Not Moving

- Check the servo connection.
- Check the assigned ESP32 GPIO pin.
- Check the servo power supply.
- Check the Arduino code.

## Wi-Fi Not Appearing

- Check that the ESP32 is powered.
- Restart the ESP32.
- Check the Wi-Fi network name and password.

## Web Control Not Working

- Connect to the `RobotArm` Wi-Fi network.
- Open the ESP32 IP address in a browser.
- Check the Serial Monitor for errors.

## Servo Movement Is Incorrect

- Check the servo home position.
- Check the servo wiring.
- Check the programmed angle values.
